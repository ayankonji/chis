### 踩坑记录
- **BrowserRouter basename 不匹配 vite base**：main.jsx 的 basename 是 `/今天吃什么`，vite.config.js 的 base 是 `/chis/`，导致路由不匹配白屏。修复：统一 basename 为 `/chis`。
- **GitHub Pages SPA 404 问题**：BrowserRouter 在 GitHub Pages 上直接访问子路由会 404，因为静态托管不支持服务端路由重写。修复：改用 HashRouter，URL 变为 `/#/draw` 形式，GitHub Pages 只处理 `/chis/` 路径，hash 部分由前端处理。

### 2026-06-03 跨设备同步 Bug 修复
- **问题**：电脑上传美食后刷新能看到，但手机上看不到
- **根因 1**：`api.js` 中的 `checkBackend()` 异步检测不稳定，一旦失败就 fallback 到 `localStorage`，导致数据只存在本机浏览器
- **根因 2**：用户上传本地图片时使用的是 `URL.createObjectURL()` 生成的 `blob:` 链接，只在当前浏览器会话有效，其他设备无法访问
- **修复 1**：彻底移除 `useBackend` 检测和 `localStorage` fallback 逻辑，`api.js` 强制直接调用 Vercel API
- **修复 2**：`AddPage.jsx` 中新增 `fileToBase64()` 函数，用户上传本地图片时自动转为 base64 data URL，再传给后端存储，确保所有设备都能正常显示图片
