## 2026-06-03 — 2.5D卡片悬浮效果 + 抽卡首页视觉优化

### 已完成工作
- **2.5D 卡片效果（FoodCard + GachaCard）**：
  - 外层 `card-25d-wrapper` 加 perspective: 800px 透视
  - 卡片 `card-25d` 类实现浮空效果 + 伪元素 `::after` 做底层厚度
  - 双阴影分层（近处硬阴影 + 远处柔和扩散阴影）
  - 金/银/铜渐变边框：使用 `background-image` 双层技术（linear-gradient + 白色填充）
  - 不改动原有卡片内部 DOM 结构
- **抽卡首页优化**：
  - 背景毛玻璃透明度提高（rgba 0.6→0.45, blur-xl→blur-md），胶卷带若隐若现
  - 胶卷带卡片放大（w-32 h-44→w-44 h-60），scale 和 opacity 提高，营造近距离感
  - 四角 SVG 美食简笔画暗纹（碗+筷子+杯子，opacity 0.04）
  - 标题字号增大（text-3xl→text-4xl/5xl/6xl），font-bold
  - 辅助文案弱化为 text-warm-gray-light
  - 抽卡按钮：渐变四色、animate-float 悬浮上浮、外发光光晕层
  - 修复点击 bug：脉冲光环加 `pointer-events: none`
  - 概率公示按钮下移 mt-12、浅灰色 text-ios-gray-3 防误触
- **CSS 新增类**：card-25d-wrapper, card-25d, card-25d-gold, card-25d-silver, card-25d-bronze, corner-decor

### 技术要点
- 品级渐变边框使用 `background-image: linear-gradient(#fff, #fff), linear-gradient(...)` + `background-clip: padding-box, border-box` 技术
- 卡片 `overflow: hidden` 不影响伪元素（伪元素在底部外溢区域被裁切，但阴影效果保留）
- Tailwind utilities 层会覆盖 components 层的 box-shadow，因此移除了 GachaCard 上的 shadow-2xl/shadow-xl
- animate-float 使用 tailwind.config.js 中已有的 float 关键帧（6s, translateY ±12px）
